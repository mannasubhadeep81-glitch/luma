# LUMIRA — Healthcare Door to Door

**One Step Towards Humanity**

This repository contains the LUMIRA MVP foundation: a responsive patient/doctor experience with the core visual language, SOS interaction, doctor discovery, departments, booking flow, and doctor command-centre overview.

## Run locally

```bash
npm install
npm run dev
```

## Current MVP

- Patient / Doctor role switch
- LUMIRA premium medical design system
- Demo mobile + OTP flow
- SOS Pulse interaction
- Virtual Care and Doorstep Care entry points
- Doctor department directory
- Nearby doctor cards and booking request flow
- Pharmacy, Lab, Ambulance and Appointment service shortcuts
- Doctor dashboard with availability and daily overview
- Local demo persistence
- Backend-ready service layer
- GitHub Pages deployment workflow
- Responsive mobile-first layout

## Production boundary

The current OTP, booking and SOS services are demo/local flows. They must not be used for real medical emergencies or production patient data. Production requires server-side authentication, authorization, encryption, audit logging, verified professional workflows, secure payments, real location services, and tested emergency-dispatch infrastructure.
