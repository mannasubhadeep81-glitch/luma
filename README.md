# LUMIRA — Healthcare Door to Door

**One Step Towards Humanity**

This repository contains the first LUMIRA MVP foundation: a responsive patient/doctor experience with the core visual language, SOS interaction, doctor discovery, departments, and doctor command-centre overview.

## Run locally

```bash
npm install
npm run dev
```

## Current MVP

- Patient / Doctor role switch
- LUMIRA premium medical design system
- SOS Pulse interaction
- Virtual Care and Doorstep Care entry points
- Doctor department directory
- Nearby doctor cards and booking entry point
- Pharmacy, Lab, Ambulance and Appointment service shortcuts
- Doctor dashboard with availability and daily overview
- Responsive mobile-first layout

## Next build layers
